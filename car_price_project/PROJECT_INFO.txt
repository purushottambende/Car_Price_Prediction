--------------------------------------------------------------------------------
1. PROJECT TITLE
--------------------------------------------------------------------------------
Second-Hand Car Price Prediction and Classification using Machine Learning

--------------------------------------------------------------------------------
2. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This project builds a machine learning system to predict the selling price of
used cars (Regression) and classify the price into Low / Medium / High categories
(Classification). The trained models are deployed as an interactive web application
built with Streamlit where users can enter car details and get an instant price
estimate along with a deal rating.

--------------------------------------------------------------------------------
3. PROBLEM STATEMENT
--------------------------------------------------------------------------------
The used car market is large and unorganized. Buyers and sellers often struggle
to determine a fair price for a second-hand vehicle. This project aims to solve
that by training ML models on historical car sale data to predict the expected
selling price and classify whether a car falls in the Low, Medium, or High price
range, helping users make informed decisions.

--------------------------------------------------------------------------------
4. OBJECTIVES
--------------------------------------------------------------------------------
- Predict the selling price of a used car given its specifications (Regression).
- Classify the price of a used car as Low, Medium, or High (Classification).
- Compare multiple regression and classification algorithms and select the best.
- Deploy the final models in a user-friendly web application.
- Provide a Deal Rating feature that tells users if an asking price is fair.

--------------------------------------------------------------------------------
5. DATASET INFORMATION
--------------------------------------------------------------------------------
Name        : Used Cars Dataset
File        : used_cars.csv (transformed to car_data_new.csv for training)
Records     : 4,009 raw rows -> 3,627 after outlier removal
Features    : 9 columns (after transformation)

Columns:
  - Car_Name       : Brand + model name of the car (string)
  - Year           : Year of manufacture, 1992-2024 (integer)
  - Selling_Price  : Selling price in Lakhs INR (float) -- TARGET
  - Present_Price  : Current showroom price in Lakhs INR (float)
  - Kms_Driven     : Total kilometres driven (integer)
  - Fuel_Type      : Petrol / Diesel / Electric (categorical)
  - Seller_Type    : Dealer (categorical)
  - Transmission   : Manual / Automatic (categorical)
  - Owner          : Number of previous owners, 0 or 1 (integer)

Unique brands : 53

--------------------------------------------------------------------------------
6. DATA PREPROCESSING
--------------------------------------------------------------------------------
Steps performed:
  1. Converted used_cars.csv (12-column raw format) to compatible 9-column
     format using transform_used_cars.py:
       - Combined brand + model -> Car_Name
       - Cleaned price ("$10,300" -> Lakhs INR)
       - Cleaned mileage ("51,000 mi." -> km)
       - Standardised fuel types (Gasoline -> Petrol, etc.)
       - Estimated Present_Price based on age ratio
  2. Coerced numeric columns to proper dtype using regex extraction.
  3. Imputed missing values:
       - Numeric columns  -> median
       - Categorical cols -> mode
  4. Dropped rows where target (Selling_Price) was missing.
  5. Removed outliers using IQR method on Selling_Price, Kms_Driven,
     and Present_Price columns.
     -> Rows reduced from 4,008 to 3,627 after outlier removal.
  6. Created price categories for classification target using pd.qcut (3 bins):
       - Low    : bottom 33%
       - Medium : middle 33%
       - High   : top 33%

--------------------------------------------------------------------------------
7. FEATURE ENGINEERING
--------------------------------------------------------------------------------
Two new features were derived inside the sklearn Pipeline:

  - Brand       : Extracted from the first word of Car_Name
                  (e.g., "Toyota Camry" -> "Toyota")
  - Car_Age     : CURRENT_YEAR (2024) - Year
                  (e.g., manufactured in 2020 -> Car_Age = 4)
  - Km_Per_Year : Kms_Driven / Car_Age
                  (average kilometres driven per year)

These are computed automatically inside custom sklearn transformers
(BrandExtractor, CarAgeFeatureEngineer) so the same transformations apply
consistently during both training and prediction.

--------------------------------------------------------------------------------
8. PREPROCESSING PIPELINE
--------------------------------------------------------------------------------
A single sklearn Pipeline is used for all models:

  BrandExtractor
       |
  CarAgeFeatureEngineer
       |
  ColumnTransformer
    |- Numeric features  -> SimpleImputer(median) -> StandardScaler
    |- Categorical feats -> SimpleImputer(mode)   -> OneHotEncoder
       |
  ML Model (Regressor or Classifier)

Numeric features  : Year, Present_Price, Kms_Driven, Owner, Car_Age, Km_Per_Year
Categorical feats : Brand, Fuel_Type, Seller_Type, Transmission

Train/Test Split  : 80% train, 20% test, random_state = 42

--------------------------------------------------------------------------------
9. ALGORITHMS EVALUATED
--------------------------------------------------------------------------------

REGRESSION (predicting Selling_Price in Lakhs INR):
  1. Simple Linear Regression
  2. Multiple Linear Regression
  3. Polynomial Regression (degree 2)   <-- BEST
  4. Ridge Regression         (alpha selected from [0.01, 0.1, 1, 10, 100])
  5. Lasso Regression         (alpha selected from [0.01, 0.1, 1, 10, 100])
  6. ElasticNet Regression
  7. Random Forest Regressor  (n_estimators=100, max_depth=10)

CLASSIFICATION (predicting Low / Medium / High):
  1. Logistic Regression
  2. K-Nearest Neighbours     (k=5)
  3. Decision Tree            (max_depth=8)   <-- BEST
  4. Random Forest Classifier (n_estimators=100, max_depth=10)
  5. Support Vector Machine   (kernel=RBF)
  6. Gaussian Naive Bayes

12. WEB APPLICATION FEATURES
--------------------------------------------------------------------------------
Framework : Streamlit
File      : app.py

Features:
  - Sidebar form with all car input fields (Brand, Year, Showroom Price,
    Kms Driven, Fuel Type, Seller Type, Transmission, Owners)
  - Vehicle Snapshot summary showing all inputs before prediction
  - Predict button that runs both models simultaneously
  - Estimated Market Price displayed in Indian Rupee format
  - Price Category badge (Low / Medium / High) with color coding
  - Class Probability bars for all three categories
  - Deal Rating feature: if user enters an asking price, it shows
      * Good Deal   : asking price > 10% below predicted
      * Fair Deal   : asking price within +/- 10% of predicted
      * Overpriced  : asking price > 10% above predicted
  - About tab with dataset details, methodology and model results

15. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
Step 1: Install dependencies
        pip install -r requirements.txt

Step 2: Transform the new dataset
        python transform_used_cars.py
        (Converts used_cars.csv -> car_data_new.csv)

Step 3: Train the models
        python train_models.py
        (This generates models/ folder and all plots in assets/)

Step 4: Launch the web app
        streamlit run app.py
        (Opens at http://localhost:8501)

--------------------------------------------------------------------------------
16. LIMITATIONS
--------------------------------------------------------------------------------
- Showroom price (Present_Price) is a strong predictor; not always available
  in real life.
- Car_Age is computed relative to a fixed year (2024); will need updating later.
- Dataset covers primarily the US used-car market; may not reflect Indian prices.
- No real-time data; prices may not reflect current market conditions.

18. CONCLUSION
--------------------------------------------------------------------------------
This project successfully demonstrates the application of machine learning for
a real-world regression and classification problem. Seven regression algorithms
and six classification algorithms were evaluated. Among all regression models,
Polynomial Regression (degree 2) achieved the best R2 of 0.9999. Among all
classifiers, Decision Tree achieved the highest accuracy of 99.45% and F1 of
0.9944. The Streamlit web app makes the models accessible without any coding
knowledge, providing instant price estimates and deal ratings to users.
